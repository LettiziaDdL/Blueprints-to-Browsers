# SkInjection Tweakments Online Store

## Purpose
SkInjection Tweakments is a planned e-commerce website for an aesthetics business. The site will let visitors shop skincare and aftercare products, buy gift cards and packages, and request a personal consultation. Treatments are performed in person after a consultation and are not sold or shipped through the website.

The goal of this project is to plan and build an accessible, easy-to-use store with a clear path from the homepage to checkout.

## Planned Pages
Home, Shop, Product Detail, Gift Cards, Book a Consultation, Cart, Checkout, Order Confirmation, About, and Contact and FAQ.
